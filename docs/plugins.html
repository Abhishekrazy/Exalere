Plugin Protocol Specification (SDK)

Exalere uses a lightweight, stateless HTTP REST protocol identical to the Stremio v3 Addon protocol. Any server responding with valid JSON can serve as an Exalere plugin.

1️⃣

1. Manifest Endpoint

GET /manifest.json
Returns metadata, supported content types (movie, series), resource actions, and ID prefixes.

2️⃣

2. Stream Endpoint

GET /stream/:type/:id.json
Receives requests for media playback (e.g. IMDb ID or Kitsu ID) and returns direct MP4/HLS streams or torrent magnet hashes.

3️⃣

3. Zero App Updates

Client apps query your hosted endpoint or community repository directly. You can fix scrapers or add mirrors at runtime with 0 app updates.

1. Endpoint: GET /manifest.json

Every plugin MUST serve a valid manifest describing its capabilities at the root URL.

manifest.json Schema & Example 
{
  "id": "com.example.streammaster",
  "name": "StreamMaster HD",
  "version": "1.0.0",
  "description": "High-speed 1080p & 4K multi-source stream scraper for movies and TV shows.",
  "resources": ["stream"],
  "types": ["movie", "series"],
  "idPrefixes": ["tt", "tmdb"],
  "catalogs": [],
  "behaviorHints": {
    "configurable": false,
    "configurationRequired": false
  }
}

2. Endpoint: GET /stream/{type}/{id}.json

Called by Exalere when the user opens a Movie or Episode.

  • Movie query: /stream/movie/tt0137523.json (Fight Club)
  • Series episode query: /stream/series/tt0944947:1:1.json (Game of Thrones S01E01, format imdbId:season:episode)
  • Anime query: /stream/series/kitsu:1234:1.json
Stream Response Format (Direct HTTP, HLS, or Torrent) 
{
  "streams": [
    {
      "name": "Server 1\n1080p",
      "title": "1080p BluRay • English AAC • Fast CDN",
      "url": "https://cdn.example.com/hls/master.m3u8",
      "behaviorHints": {
        "proxyHeaders": {
          "request": {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)",
            "Referer": "https://source.example.com/"
          }
        }
      },
      "subtitles": [
        {
          "lang": "en",
          "name": "English [CC]",
          "url": "https://cdn.example.com/subs/en.vtt"

}

⚠️ Mandatory Header: CORS

Your plugin endpoint MUST return Access-Control-Allow-Origin: * on all responses so both Exalere clients and the online validator can query your service without browser security blocks.

Ready-to-Deploy Starter Templates

Pick your stack and deploy for free in under 3 minutes.

Cloudflare Workers runs on 300+ global edge locations with zero server maintenance. Free tier provides 100,000 requests/day.

worker.js (Cloudflare Workers) 
export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);
    const corsHeaders = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Headers': '*',
      'Content-Type': 'application/json; charset=utf-8'
    };

    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: corsHeaders });
    }

    // 1. Manifest
    if (url.pathname === '/manifest.json' || url.pathname === '/') {
      return new Response(JSON.stringify({
        id: 'org.community.exalere.cf-plugin',
        name: 'Cloudflare Edge Streamer',
        version: '1.0.0',
        description: 'Serverless streaming plugin hosted on Cloudflare Workers',
        resources: ['stream'],
        types: ['movie', 'series'],
        idPrefixes: ['tt']
      }), { headers: corsHeaders });
    }

    // 2. Stream Resolver
    const streamMatch = url.pathname.match(/^\/stream\/(movie|series)\/([^\/]+)\.json$/);
    if (streamMatch) {
      const [_, type, id] = streamMatch;
      // Scrape or resolve stream based on IMDb ID
      const streams = [
        {
          name: 'CF Worker\n1080p',
          title: `Stream for ${id} (Fast Edge)`,
          url: 'https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8',
          behaviorHints: {
            proxyHeaders: {
              request: { 'User-Agent': 'Exalere/1.0' }
            }
          }
        }
      ];
      return new Response(JSON.stringify({ streams }), { headers: corsHeaders });
    }

    return new Response(JSON.stringify({ error: 'Not found' }), { status: 404, headers: corsHeaders });
  }
};

server.js (Node.js Express) 
const express = require('express');
const cors = require('cors');

const app = express();
app.use(cors());

const MANIFEST = {
  id: 'org.community.node-streamer',
  name: 'Node Stream Resolver',
  version: '1.0.0',
  description: 'Express-based stream resolver plugin for Exalere',
  resources: ['stream'],
  types: ['movie', 'series'],
  idPrefixes: ['tt']
};

app.get('/manifest.json', (req, res) => {
  res.json(MANIFEST);
});

app.get('/stream/:type/:id.json', async (req, res) => {
  const { type, id } = req.params;
  // Parse IMDb ID and Episode (e.g. tt0944947:1:1)
  const [imdbId, season, episode] = id.split(':');

  // Perform web scraping or API query here...
  res.json({
    streams: [
      {
        name: 'Node Server\n1080p',
        title: `${type.toUpperCase()} • ${imdbId} • 1080p`,
        url: 'https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4'
      }
    ]
  });
});

const PORT = process.env.PORT || 7000;
app.listen(PORT, () => console.log(`Plugin server running on port ${PORT}`));
