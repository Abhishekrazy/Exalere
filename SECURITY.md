# Security Policy

## Supported Versions

Only the latest release and the current active development branches receive active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Exalere team takes security seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report security issues responsibly:

1. **GitHub Advisory (Preferred)**: Open a private draft security advisory directly via the repository's **Security > Advisories** tab on GitHub.
2. **Direct Contact**: Contact repository maintainers via the contact details specified in the maintainer's GitHub profile (`github.com/${GITHUB_REPOSITORY_OWNER}`).

### What to Include in Your Report:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Relevant platform information (Windows Desktop, Android Mobile, or Android TV).
- Suggested remediation or patch if you have identified one.

### Response Timeline
- **Initial Response**: We strive to acknowledge receipt of security reports within **48 hours**.
- **Assessment & Fix**: We will triage and assess the vulnerability, keeping you informed of resolution progress.
- **Disclosure**: Public disclosure will be coordinated once an update is available to protect users.

Thank you for helping keep Exalere and its community safe!
